# Prompt-Master

Simple AI-powered prompt generator using Google's Gemini models.

## Features
- Dark UI powered by Gradio
- Generate prompts from images
- Generate prompts from title and keywords
- One-click generate & copy
- Clear buttons and refined layout
- Larger 512×512 image upload area

## Usage
```bash
pip install -r requirements.txt
python prompt_master.py
```
Then open <http://localhost:7860> in your browser. Set `GEMINI_API_KEY` environment variable to override the built-in sample key.
